# Nexus OS - Product Requirements Document (PRD)

## Overview
Nexus OS é o sistema operacional de orquestração interna para a Konig Systems, projetado para gerenciar o lifecycle completo de produtos digitais, desde o lead até o suporte.

## Key Features
1. **Sales CRM**: Gestão de funil de vendas.
2. **Portfolio Management**: Visão 360 de produtos e saúde do ecossistema.
3. **Engineering Kanban**: Gestão de tarefas técnicas via Supabase.
4. **Support Center**: Triagem de bugs via Carla QA (AI) e escalada para Orion (Dev AI).
5. **Squad Hub**: Comunicação em tempo real entre mentes humanas e artificiais.
6. **Focus Space**: Organização anti-ADHD para o CEO.

## Tech Stack
- **Frontend**: Angular 21+, Signals, Tailwind CSS.
- **Backend/DB**: Supabase (Auth, Realtime, DB).
- **Intelligence**: Google Gemini 2.0 (via Nexus AI Service).
